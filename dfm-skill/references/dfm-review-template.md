# DFM Review Template

Use this template for manufacturability reviews. Keep it short unless the user asks for a formal report.

```markdown
## DFM Review

Assumptions:
- Process:
- Material:
- Quantity:
- Critical interfaces:

Findings:
- [Severity] [Feature or area]: [Issue]. Recommendation: [Specific change or check].

Validation:
- Minimum wall/feature checks:
- Clearance/tolerance checks:
- Tooling/support/fixturing checks:
- Export or drawing requirements:

Residual risks:
- [Risk that needs supplier confirmation, prototype testing, or user decision.]
```

## Severity Guide

- Critical: likely to fail manufacturing, assembly, or core function.
- Major: manufacturable but expensive, fragile, inconsistent, or likely to need rework.
- Minor: improvement for cost, quality, handling, or clarity.
- Note: assumption, supplier question, or optional improvement.
